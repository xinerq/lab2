# Geometric Lib — Библиотека геометрических функций

Библиотека `geometric_lib` предоставляет удобный инструментарий на языке Python для решения базовых геометрических задач: вычисления площадей и периметров основных плоских фигур (круга, прямоугольника, квадрата и треугольника).

## Общее описание решения

Проект состоит из набора независимых модулей, каждый из которых отвечает за математические расчеты для конкретной геометрической фигуры:

* **`circle.py`** — операции с кругом/окружностью.

* **`rectangle.py`** — операции с прямоугольником.

* **`square.py`** — операции с квадратом.

* **`triangle.py`** — операции с треугольником.

Все функции принимают числовые параметры (целые числа или числа с плавающей точкой) и возвращают вычисленные значения площади $S$ или периметра $P$.

## Описание функций с примерами вызова

### 1. Модуль `circle.py`

#### `area(r)`

Вычисляет площадь круга по его радиусу.

* **Параметры:**

  * `r` (`int` | `float`): радиус круга.

* **Возвращаемое значение:**

  * `float`: площадь круга, рассчитанная по формуле $S = \pi r^2$.

* **Пример вызова:**

  ```
  import circle
  
  res = circle.area(5)
  print(res)  # Выведет: 78.53981633974483
  
  ```

#### `perimeter(r)`

Вычисляет периметр (длину окружности) круга по его радиусу.

* **Параметры:**

  * `r` (`int` | `float`): радиус круга.

* **Возвращаемое значение:**

  * `float`: длина окружности, рассчитанная по формуле $P = 2 \pi r$.

* **Пример вызова:**

  ```
  import circle
  
  res = circle.perimeter(5)
  print(res)  # Выведет: 31.41592653589793
  
  ```

### 2. Модуль `rectangle.py`

#### `area(a, b)`

Вычисляет площадь прямоугольника по длинам двух его смежных сторон.

* **Параметры:**

  * `a` (`int` | `float`): длина первой стороны.

  * `b` (`int` | `float`): длина второй стороны.

* **Возвращаемое значение:**

  * `int` | `float`: площадь прямоугольника, рассчитанная по формуле $S = a \cdot b$.

* **Пример вызова:**

  ```
  import rectangle
  
  res = rectangle.area(3, 5)
  print(res)  # Выведет: 15
  
  ```

#### `perimeter(a, b)`

Вычисляет периметр прямоугольника по длинам двух его смежных сторон.

* **Параметры:**

  * `a` (`int` | `float`): длина первой стороны.

  * `b` (`int` | `float`): длина второй стороны.

* **Возвращаемое значение:**

  * `int` | `float`: периметр прямоугольника, рассчитанный по формуле $P = 2(a + b)$.

* **Пример вызова:**

  ```
  import rectangle
  
  res = rectangle.perimeter(3, 5)
  print(res)  # Выведет: 16
  
  ```

### 3. Модуль `square.py`

#### `area(a)`

Вычисляет площадь квадрата по длине его стороны.

* **Параметры:**

  * `a` (`int` | `float`): сторона квадрата.

* **Возвращаемое значение:**

  * `int` | `float`: площадь квадрата, рассчитанная по формуле $S = a^2$.

* **Пример вызова:**

  ```
  import square
  
  res = square.area(5)
  print(res)  # Выведет: 25
  
  ```

#### `perimeter(a)`

Вычисляет периметр квадрата по длине его стороны.

* **Параметры:**

  * `a` (`int` | `float`): сторона квадрата.

* **Возвращаемое значение:**

  * `int` | `float`: периметр квадрата, рассчитанный по формуле $P = 4a$.

* **Пример вызова:**

  ```
  import square
  
  res = square.perimeter(5)
  print(res)  # Выведет: 20
  
  ```

### 4. Модуль `triangle.py`

#### `area(a, h)`

Вычисляет площадь треугольника по длине стороны и опущенной на нее высоте.

* **Параметры:**

  * `a` (`int` | `float`): сторона треугольника.

  * `h` (`int` | `float`): высота, опущенная на сторону `a`.

* **Возвращаемое значение:**

  * `float` | `int`: площадь треугольника, рассчитанная по формуле $S = \frac{1}{2} a \cdot h$.

* **Пример вызова:**

  ```
  import triangle
  
  res = triangle.area(3, 5)
  print(res)  # Выведет: 7.5
  
  ```

#### `perimeter(a, b, c)`

Вычисляет периметр треугольника по длинам трех его сторон.

* **Параметры:**

  * `a` (`int` | `float`): первая сторона.

  * `b` (`int` | `float`): вторая сторона.

  * `c` (`int` | `float`): третья сторона.

* **Возвращаемое значение:**

  * `int` | `float`: периметр треугольника, рассчитанный по формуле $P = a + b + c$.

* **Пример вызова:**

  ```
  import triangle
  
  res = triangle.perimeter(3, 4, 5)
  print(res)  # Выведет: 12
  
  ```
